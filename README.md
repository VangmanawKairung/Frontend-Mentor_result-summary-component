## My process

### Built with

- Semantic HTML5 markup
- CSS Custom Properties (CSS variables)
- Flexbox & CSS Grid
- Mobile-first workflow
- BEM methodology
- [React](https://react.dev/) - JS library
- [Vite](https://vite.dev/) - Frontend build tool

### What I learned

During this project, I really leveled up my skills in structuring scalable and maintainable front-end code. I learned how to effectively combine React components with strict BEM methodology to keep styles modular and avoid specificity issues. One of the key takeaways was mastering CSS relative color syntax (`hsl(from ... h s l / 0.1)`) to handle dynamic background opacities cleanly based on theme variables. I also gained a deeper understanding of accessibility standards, ensuring proper semantic HTML landmarks and focus states for keyboard navigation.

### Continued development

I want to continue improving my component architecture and exploring advanced animations or interactive states in future React projects. I also plan to practice integrating data fetching and handling more complex state logic to make my user interfaces even more robust.
